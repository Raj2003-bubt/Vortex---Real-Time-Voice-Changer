## Recommended Git workflow

- `main`: stable demonstration-ready code
- `audio-engine`: capture, processing and output work
- `ui`: JavaFX interface work
- `testing-docs`: tests, user guide and final documentation

Use pull requests for integration and keep issues for bugs, device compatibility and preset tuning.
